# AI 공사계약 통합지원

견적서에서 시작한 정보를 품의, 계약, 착공, 준공, 검사검수와 하자관리까지 이어서 사용하는 교육행정용 공사계약 업무 프로토타입입니다.

## 현재 구현 범위 — Phase 1

- 한국어 홈 화면과 견적서 첨부 영역
- 계약 현황판과 샘플 계약 6건
- 계약 상세화면과 전체 업무 Timeline
- 담당자 확인 기반의 순차 단계변경
- 착공·준공·하자검사 D-Day 계산
- 계약정보와 단계변경 이력 DB 저장

지식관리, AI 문서분석, 견적검토와 서류 누락검사는 후속 Phase에서 단계별로 구현합니다.

## 실행

```bash
npm install
npm run dev
```
